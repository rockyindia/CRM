# CRM – Business Relationship Management System

A modern CRM project designed to help businesses organize customer relationships, manage leads, track sales activities, and improve team productivity.

## About the Project

CRM is a business management software project created to simplify customer relationship management and business operations.

The long-term vision is to make this project useful for businesses, sales teams, and developers through continuous development, better documentation, and community contributions.

## Project Structure

- `backend/` – Backend application
- `frontend/` – Frontend application
- `memory/` – Project memory and supporting resources
- `tests/` – Test files
- `test_reports/` – Test reports
- `design_guidelines.json` – Design guidelines

## Project Goals

- Simplify business and customer management.
- Improve sales team productivity.
- Support organized lead management.
- Improve business workflows.
- Encourage maintainable and scalable software development.
- Build a developer-friendly project.

## Security

- Never commit API keys, passwords, or secret tokens.
- Never upload customer or confidential business data.
- Use environment variables for sensitive configuration.
- Report security vulnerabilities privately to the maintainer.
